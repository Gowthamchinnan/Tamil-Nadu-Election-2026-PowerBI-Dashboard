# Tamil Nadu Election 2026 - Power BI Dashboard

## Project Overview

This project is an interactive Power BI dashboard developed to analyze Tamil Nadu Election 2026 data.

The dashboard provides a clear overview of party performance, vote share, candidate details, criminal cases, education levels, and candidate assets.

The main objective of this project is to convert raw election data into meaningful and easy-to-understand visual insights using Power BI.

---

## Tools & Technologies Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- Excel / CSV Dataset
- Data Visualization
- Data Cleaning and Transformation
- Interactive Filters and Slicers

---

## Dashboard Pages

The report contains two main pages:

### 1. Election Dashboard

The Election Dashboard provides an overall summary of the election data.

It includes:

- Total Constituencies
- Target Majority
- Party-wise Won Seats
- Party-wise Vote Share
- Candidate Name Filter
- Candidate Criminal Cases
- Candidate Education
- Candidate Assets
- Candidate and Party Analysis

### Key Party Summary

Based on the dataset used in this project:

- TVK - 109 Seats
- DMK - 59 Seats
- AIADMK - 47 Seats
- Target Majority - 118 Seats

### Vote Share

The dashboard also compares the vote share of the major parties:

- TVK - 34.92%
- DMK - 31.39%
- AIADMK - 27.22%

A pie chart is used to visualize the seat distribution among parties.

---

## 2. Reports Page

The Reports page provides detailed analysis of candidates and parties.

### KPI Cards

The page contains important summary metrics such as:

- Candidate Count - 236
- Candidates With Criminal Cases - 160
- Total Declared Cases - 561
- Median Candidate Assets - ₹7.24 Crore

### Declared Cases by Party

A horizontal bar chart is used to compare the number of declared criminal cases among candidates from different political parties.

The visual helps identify which parties have candidates with a higher number of declared cases.

### Assets by Party

The dashboard compares:

- Average Assets
- Median Assets

for candidates belonging to different political parties.

This helps understand the financial profile of candidates across parties.

### Candidate Count by Education

Candidate education levels are analyzed using a horizontal bar chart.

Education categories include:

- Graduate
- Post Graduate
- Graduate Professional
- 10th Pass
- 12th Pass
- Doctorate
- 8th Pass
- 5th Pass
- Others
